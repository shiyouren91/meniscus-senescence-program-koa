# Data and Code Availability

The repository contains the reviewer-driven HVG-only discovery, independent HRA001986 matching, tissue-stratified bulk evaluation, manuscript-audit scripts, derived tables, revised figures, and supporting workbook for this study. Raw sequencing data and large processed single-cell objects are not redistributed.

Public source data should be downloaded from the repositories listed in the manuscript. The author-provided processed HRA001986 h5ad files are not redistributed; the underlying sequencing data are available under HRA001986, and requests for the exact processed files may be directed to the source-study authors.

Repository URL: https://github.com/shiyouren91/meniscus-senescence-program-koa
